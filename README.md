# Expense Tracker API 🚀

A production-style backend API for managing personal expenses, tracking spending habits, and generating financial insights.

This project is built to demonstrate backend engineering concepts including REST APIs, authentication, database design, scalable architecture, and cloud-ready development practices.

---

# Project Overview

Expense Tracker API is a backend application that allows users to securely manage their personal expenses.

Users will be able to:

- Create and manage expense records
- Categorize spending
- View monthly summaries
- Search and filter transactions
- Analyze spending patterns
- Receive personalized financial insights

The project follows a scalable backend architecture with separation of concerns between routes, controllers, services, and database layers.

---

# Features

## Phase 1 - Core Backend

- User registration and login
- JWT-based authentication
- Password encryption using bcrypt
- Create expenses
- View expenses
- Update expenses
- Delete expenses
- Expense categories
- Search and filtering
- Monthly expense summaries


## Phase 2 - Advanced Features

- PostgreSQL database integration
- Prisma ORM
- Docker containerization
- Redis caching
- Email notifications
- Budget alerts
- CSV export
- Analytics dashboard
- AI-powered spending insights
